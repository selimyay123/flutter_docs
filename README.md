# Flutter & Dart Mastery — From Zero to Interview-Ready

Welcome. This folder is your personal course.
You do **not** need to know anything about Flutter or Dart. We start from zero.

The goal is bigger than syntax. By the end you should:

1. Write clean, idiomatic **Dart**.
2. Build real **Flutter** apps with sound architecture.
3. **Think like a programmer**: break problems down, design algorithms, reason about cost.
4. Pass a senior-level **interview**.

---

## How every lesson is built

Each file has the same shape:

| Part | Purpose |
|------|---------|
| Goal | What you will learn |
| Concepts | Short, simple explanations with code |
| Common mistakes | Traps that beginners (and seniors) fall into |
| Code challenge | Small task. Solve it **before** looking at the solution |
| Interview questions | **Last section.** Answer out loud, then check the hints |

Rule: **never skip the challenge and the questions.** Reading is not learning. Doing is.

## Daily routine (the 3-part habit)

1. **Learn** (30 min): read one lesson, type every example by hand. Do not copy-paste.
2. **Solve** (45 min): one challenge from the lesson, plus one algorithm problem.
3. **Explain** (15 min): answer the interview questions out loud, as if to a teammate.

If you cannot explain it simply, you do not understand it yet.

---

## Where to run code

- **Dart code:** [DartPad](https://dartpad.dev) (no install) or `dart run file.dart`.
- **Flutter code:** your local setup from [`00_start_here/02_setup_environment.md`](00_start_here/02_setup_environment.md).
- Put your own solutions in a folder named `my_solutions/` (create it yourself). Keep everything in Git.
